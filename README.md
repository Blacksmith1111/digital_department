Проект, написанный на Python3 с использованием Django. Представляет из себя приложение для заучивания слов.
Реализованы: возможность добавления набора карт со словами, возможность добавления карт в набор, возможность редактирования наборов и карт в отдельности,
возможность проведения тренировки для заучивания с выведением итогового результата по её завершении, валидация входной информации при создании и редактировании карт.
